# color

This is a library to create and manage ANSI ESC-sequences.

The implementation is derived from the very well known Fatih's "color" module.
...only completely refactored, modernized and [most probably] much more
efficient and performant.
 - StringBuilder used pervasively
 - Optimized caching

And, finally, removed external dependencies.


This version is Linux-ONLY, for ANSI-compatible terminals (non-dumb favored ;)
